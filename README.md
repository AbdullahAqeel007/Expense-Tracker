# 💰 Expense Tracker

A simple **Python Expense Tracker** that allows users to record their daily expenses, view all recorded expenses, and calculate the total amount spent.

This project was created as a beginner Python project to practice basic programming concepts.

## ✨ Features
* Add a new expense
* Enter expense description
* Enter expense amount
* Enter expense category
* View all recorded expenses
* Calculate total expenses
* Simple command-line interface
* Basic error handling for invalid amounts

## 🛠️ Technologies Used

* **Python 3**
* Lists
* Dictionaries
* Functions
* Loops
* Conditional statements
* Exception handling
* Formatted strings

```text
Expense-Tracker/

```

## 🚀 How to Run

### 1. Install Python

Make sure Python 3 is installed on your computer.

You can check by running:

```bash
python --version
```

### 2. Download or Clone the Repository

Clone the repository using:

```bash
git clone https://github.com/YOUR-USERNAME/Expense-Tracker.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 3. Open the Project Folder

```bash
cd Expense-Tracker
```

### 4. Run the Program

```bash
python main.py
```
